Day 04 — IT Candidate Sourcing Strategy

Objective

To learn how an IT recruiter sources suitable candidates for technical roles using different recruitment channels and Boolean search techniques.

Roles Covered

* Java Developer
* QA Engineer
* Python Developer

Sourcing Channels

* LinkedIn
* Naukri
* Indeed
* Employee Referrals
* Campus Hiring
* Direct Applications

Boolean Search Practice

Java Developer

Broad Search

Java AND SQL

Balanced Search

("Java Developer" OR "Java Engineer") AND "Spring Boot" AND SQL

Narrow Search

("Java Developer" OR "Backend Developer") AND "Spring Boot" AND SQL AND "REST API" NOT Senior NOT Manager

QA Engineer

Broad Search

QA AND Testing

Balanced Search

("QA Engineer" OR "QA Tester") AND "Manual Testing" AND Selenium AND SQL

Narrow Search

("QA Engineer" OR "Test Engineer") AND Selenium AND SQL AND ("Test Automation" OR Automation) NOT Manager

Python Developer

Broad Search

Python AND SQL

Balanced Search

("Python Developer" OR "Python Engineer") AND (Django OR Flask) AND SQL

Narrow Search

("Python Developer" OR "Backend Developer") AND Python AND (Django OR FastAPI) AND SQL AND "REST API" NOT Senior NOT Manager

Key Learning

This project helped me understand that effective IT candidate sourcing involves:

1. Understanding the Job Description
2. Identifying must-have skills
3. Choosing the right sourcing channel
4. Creating Boolean search strings
5. Targeting relevant candidates
6. Screening candidates against requirements
7. Tracking candidates through the recruitment funnel
